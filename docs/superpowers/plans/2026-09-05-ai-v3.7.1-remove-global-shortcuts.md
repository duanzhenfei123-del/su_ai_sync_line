# AI v3.7.1 Remove Global Shortcuts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release AI plugin v3.7.1 without any global-shortcut UI, keyboard hook, helper executable, shortcut IPC, or shortcut polling while preserving PNG/outline export and the v3.7 SU protocol.

**Architecture:** Remove the shortcut feature vertically from the CEP HTML/CSS/JavaScript, ExtendScript bridge, and installable payload. Build a separate v3.7.1 installer source tree that stops the legacy v3.7 helper through its heartbeat contract, keeps a persistent ZIP backup, replaces only the exact extension directory, and embeds the shortcut-free payload.

**Tech Stack:** Adobe CEP HTML/CSS/ES5 JavaScript, ExtendScript, Node.js assertions, PowerShell 7, C# 5 / .NET Framework 4.8 WinForms, `System.IO.Compression`, Windows `csc.exe`, Git.

## Global Constraints

- AI plugin version is `v3.7.1`; installer file version is `3.7.1.0`.
- SketchUp remains `v3.7`; do not modify `source/`, the RBZ, or the schema-v2 protocol.
- Remove the shortcut controls without adding replacement controls or notices; the remaining panel content naturally moves upward.
- The installable extension and both v3.7.1 artifacts must not contain `SUAIShortcutHost.exe`.
- Preserve `SU_AI_PNG_Export_v3.7.zip` and `SU_AI_PNG_Export_v3.7_Setup.exe` byte-for-byte.
- Do not restart Illustrator, terminate Illustrator, or force-kill the legacy helper.
- Default install scope remains `%APPDATA%\Adobe\CEP\extensions\su-ai-png-export`; never alter sibling extensions.
- Persist upgrade backups under `%APPDATA%\SU_AI_PNG_Export\backups\` and retain them during uninstall.
- Keep the installer unsigned and dependent only on Windows/.NET components already present.
- Illustrator 2023 keyboard and focus checks remain explicitly “待复测” until run on the affected computer.

The injectable install overload must validate/extract the payload first, then call `PrepareLegacyShortcutRemoval(dataRoot, TimeSpan.FromSeconds(5))`, create a persistent backup only when the old target exists, and use the existing staging/transaction rollback. Implement the helpers with these rules:

```csharp
private static readonly string[] LegacyRuntimeFiles = {
    "panel.heartbeat", "shortcut.command", "shortcuts.cfg"
};

private static void PrepareLegacyShortcutRemoval(string dataRoot, TimeSpan timeout)
{
    Directory.CreateDirectory(dataRoot);
    foreach (var name in LegacyRuntimeFiles) TryDeleteFile(Path.Combine(dataRoot, name));
    var status = Path.Combine(dataRoot, "shortcut-host.status");
    var deadline = DateTime.UtcNow + timeout;
    while (File.Exists(status) && LegacyHostIsRunning(status))
    {
        if (DateTime.UtcNow >= deadline)
            throw new IOException("旧版快捷键程序仍在运行。请关闭旧版 AI 插件面板后重试；Illustrator 不会被强制关闭。");
        Thread.Sleep(100);
    }
    TryDeleteFile(status);
}

private static string CreatePersistentBackup(string target, string dataRoot)
{
    var backupRoot = Path.Combine(dataRoot, "backups");
    Directory.CreateDirectory(backupRoot);
    var name = "su-ai-png-export-" + DateTime.Now.ToString("yyyyMMdd-HHmmssfff") + ".zip";
    var path = Path.Combine(backupRoot, name);
    ZipFile.CreateFromDirectory(target, path, CompressionLevel.Optimal, false);
    return path;
}
```

`LegacyHostIsRunning` must parse the PID from the status file, use `Process.GetProcessById`, return true only when the live process name equals `SUAIShortcutHost` case-insensitively, and treat unreadable/invalid/stale status as false. It must never terminate the process. `Uninstall(extensionsRoot,dataRoot)` performs the same cleanup before deleting only `TargetPath(extensionsRoot)` and never deletes `dataRoot/backups`.
