# SU+AI v3.7 Protocol Alignment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 AI v3.7 明确导出复合路径、文字分组和真实绘制顺序，让 SU v3.7 确定、安全且向后兼容地读取这些数据。

**Architecture:** 不新建协议框架；直接修改现有 Illustrator `main.jsx` 和 SketchUp `Importer`。AI CEP 源码完整纳入仓库，测试使用 Node 标准库加载 JSX；SU 继续使用现有 Ruby 测试入口。

**Tech Stack:** Adobe CEP/ExtendScript、Node.js 标准库、SketchUp Ruby API、Ruby、ZIP/RBZ。

## Global Constraints

- AI 与 SU 产品版本均为 `3.7`，数据 `schemaVersion` 为 `2`。
- 两端面板布局和操作步骤不变，只更新版本文字。
- v3.6 JSON 作为协议 1继续兼容；未来协议必须在创建实体前拒绝。
- 不添加第三方依赖，不新建协议类，不重写快捷键宿主。
- 不在本阶段实现图片、蒙版、渐变或安装器 EXE 重写。
- AI 不生成文件日志；SU 每次点击导入只保留当前一份日志。
- 所有行为修改先观察测试失败，再写最小实现。

var COMPOUND_COUNTER = 0;
function itemZIndex(item, fallback) {
    try {

    return Number(fallback || 0);
}
function nextCompoundKey() {
    return "compound_" + padZero(COMPOUND_COUNTER++, 4);
}

function aCP(item, ps, s, compoundKey) {

        d.id = "p_" + padZero(ps.length, 3);
        d.name = item.name || ("p" + ps.length);
        d.compoundKey = key;

}

- [ ] **Step 3: 写最小实现**

```javascript
function ownedSyncFile(name) {
    return /^sync_.*\.(json|tmp)$/i.test(name) || /^latest_sync\.json\.tmp$/i.test(name);
}
function esc(s) {
    return String(s).replace(/[\\"\u0000-\u001F]/g, function(ch) {
        var map = {'\\':'\\\\','"':'\\"','\b':'\\b','\f':'\\f','\n':'\\n','\r':'\\r','\t':'\\t'};
        if (map[ch]) return map[ch];
        return '\\u' + ('000' + ch.charCodeAt(0).toString(16)).slice(-4);
    });
}
```

把仍被几何函数调用的 `log` 改为空函数；删除 `logToFile` 及其调用。清理循环只调用 `ownedSyncFile(name)`。JSON 根对象写入 `"schemaVersion":2`，输出路径固定为 `latest_sync.json`，临时路径固定为 `latest_sync.json.tmp`。

- [ ] **Step 3: 写最小 Importer 实现**

JSON 解析后、读取内容前执行 `validate_data!(data)`。私有实现：

```ruby
def validate_data!(data)
  raise ArgumentError, '同步数据根节点必须是对象' unless data.is_a?(Hash)
  raw_version = data.fetch('schemaVersion', 1)
  begin
    version = Integer(raw_version)
  rescue ArgumentError, TypeError
    raise ArgumentError, "无效的数据协议版本: #{raw_version.inspect}"
  end
  raise ArgumentError, "不支持的数据协议版本: #{version}" unless [1, 2].include?(version)
  %w[paths groups images].each do |key|
    raise ArgumentError, "#{key} 必须是数组" if data.key?(key) && !data[key].is_a?(Array)
  end
  version
end
```

`locate_json` 保留固定文件优先，再使用：

```ruby
candidates = Dir.glob(File.join(directory, 'sync_*.json')).select { |path| File.file?(path) }
candidates.max_by { |path| File.mtime(path) }
```

`groups` 改为：

```ruby
groups = (data['groups'] || []).map { |group| normalize_group(group) }
```

递归规范化：

```ruby
def normalize_group(group)
  raise ArgumentError, 'group 必须是对象' unless group.is_a?(Hash)
  copy = group.dup
  copy['paths'] = (group['paths'] || []).map { |path| normalize_path(path) }
  copy['groups'] = (group['groups'] || []).map { |child| normalize_group(child) }
  copy
end
```

def text_path?(path)

end

def text_group_key(path)
  path['textGroupKey'] || path['textGroupId'] || 'text'
end
