# AI v3.7 EXE 安装器设计

## 目标

将 `illustrator/su-ai-png-export` 中的 Illustrator CEP 插件封装为 Windows 图形安装器 `SU_AI_PNG_Export_v3.7_Setup.exe`。安装器沿用 v3.6 的使用方式，不改变插件面板、导出流程或协议行为。

## 方案

使用 Windows 自带的 .NET Framework 4.8 C# 编译器构建 WinForms 单文件程序。安装器将当前 v3.7 插件文件打包为名为 `PluginPayload` 的内嵌 ZIP 资源，运行时不依赖 PowerShell、7-Zip、NSIS、Inno Setup 或联网下载。

仓库新增独立的安装器源码和构建脚本。构建脚本从 `illustrator/su-ai-png-export` 生成负载、编译 EXE，并检查内嵌文件清单与源目录一致。以后升级版本时可以重复使用同一套构建流程。

## 用户界面

安装器显示产品名称、v3.7 版本、安装位置、当前状态，以及“安装插件”和“卸载插件”两个按钮。成功安装后提示用户重启 Illustrator，并从“窗口 > 扩展（旧版）> SU+AI PNG 导出”打开面板。

界面不提供安装路径修改、组件选择或联网更新，避免增加与现有安装方式无关的选项。

## 安装流程

1. 从 EXE 的 `PluginPayload` 资源解压到当前用户临时目录。
2. 验证负载根目录、`CSXS/manifest.xml` 和 `host/main.jsx` 存在。
3. 安装到 `%APPDATA%\Adobe\CEP\extensions\su-ai-png-export`，无需管理员权限。
4. 如目标插件已存在，只替换这个精确目录；安装失败时恢复旧目录。
5. 在当前用户注册表中为 `CSXS.9` 至 `CSXS.20` 设置字符串值 `PlayerDebugMode=1`。
6. 删除安装过程产生的临时文件。

安装器不得删除或修改其他 Adobe 扩展、导出目录、Illustrator 文档或 SU 插件。

## 卸载流程

卸载只删除 `%APPDATA%\Adobe\CEP\extensions\su-ai-png-export`。`PlayerDebugMode` 是 Adobe CEP 的共享配置，卸载时保留，避免影响其他未签名 CEP 扩展。

若插件目录不存在，卸载操作显示“未安装”，不作为错误。

## 错误处理

- 无法读取内嵌负载时停止安装并显示错误。
- 负载结构不完整时不触碰现有安装。
- 替换目标目录失败时尝试恢复旧版本，并报告失败原因。
- 临时目录清理失败不覆盖主要安装结果，但不向用户报告虚假成功。
- 界面操作期间禁用安装和卸载按钮，防止重复执行。

## 构建与发布

构建产物版本信息为 `3.7.0.0`，产品描述为 `SU+AI PNG Export Installer`，公司名沿用“段土土”。最终 EXE 放在仓库根目录并上传到 `feature/v3.7-protocol` 分支。

本次不配置数字签名，行为与 v3.6 安装器一致。Windows 可能显示“未知发布者”。代码签名证书不属于本次范围。

## 验收标准

- EXE 可在无管理员权限的 Windows 用户下启动。
- 内嵌负载包含 AI v3.7 源目录的全部 12 个文件，内容逐项一致。
- 安装后目标目录与源插件文件逐项一致。
- `PlayerDebugMode` 覆盖 CSXS 9–20。
- 重复安装可以安全覆盖当前版本。
- 卸载只移除目标插件目录。
- EXE 的文件版本、产品版本和界面版本均为 v3.7。
- AI 协议测试继续通过，插件面板布局没有变化。
