# SU+AI 同步导入 v3.6.3 橙子版合并设计

## 目标

以橙子二次开发版为主体合并功能，同时补回并保留当前 v3.6.2 已验证稳定的几何、材质、日志和跨平台修复。最终版本号为 v3.6.3。

## 合并原则

- 橙子版提供新增工作流和导入组结构。
- v3.6.2 提供稳定的几何与兼容性实现。
- 冲突时优先保证已经实际验证的文字镂空、颜色、法线、图片与日志行为。
- 不直接覆盖整个插件包；按文件和方法合并，避免旧逻辑回退。
- 面板保留原有导入区域和操作习惯，在其基础上增加功能区。
- 作者信息保持“作者：段土土”，不加入二次开发署名。

## 纳入的橙子版能力

### 按图层叠放

- 面板新增“按图层叠放”开关，默认关闭。
- 开启后显示“层间距(mm)”，默认值为 10mm。
- 每个顶层路径或 AI 组作为一个图层单元。
- 存在有效且有区分度的 `zIndex` 时按 `zIndex` 排序，否则保持 JSON 数组顺序。
- AI 最上层对应 SketchUp 最高 Z。
- 叠层导入保留总组和内部图层子组，便于选择与后续落面。
- 开关状态和层间距通过 SketchUp 首选项持久化。

### 坐落物体表面

- 功能按钮放在导入面板中。
- 处理当前选择中的组、组件实例和图片实体。
- 在对象包围盒底部使用 3×3 采样点向下射线检测。
- 在所有有效命中中取不高于对象底面的最高支撑面。
- 有命中时只沿 Z 轴移动，使对象底面落到支撑面。
- 无命中时保持原位置，不弹窗、不提示、不生成辅助线。
- 整个操作纳入一个可撤销事务；异常时回滚并显示错误。

### 导入贴图对齐

- 功能按钮放在导入面板中。
- 使用当前选中的第一个组或组件实例作为尺寸参考。
- 通过 SketchUp 文件选择器选择 PNG、JPG、JPEG、BMP、TIF 或 TIFF。
- 按参考对象包围盒的 X×Y 尺寸创建临时 `Sketchup::Image`。
- 图片左下角对齐参考对象包围盒的 XY 最小点，Z 位于参考对象顶面上方 10mm。
- 用户取消选图时静默结束。
- 未选择有效参考对象或图片创建失败时显示明确提示。
- 操作支持撤销，异常时回滚。

### 保留导入组

- 普通导入不再执行“炸开临时组后重新建组”。
- 直接将临时组命名为最终导入组并保留。
- 避免组原点、选择框和实际几何位置脱节。
- 对齐原点后检查总组包围盒最小 X、Y 是否接近零。

### 橙子版其他行为

- 拉伸后递归处理需要软化的边。
- 保留橙子版面向图层叠放的导入组织方式，但不采用会破坏当前几何稳定性的旧构建实现。

## 必须保留的 v3.6.2 能力

- 无文字标记但同色、闭合、存在嵌套关系的转曲文字识别。
- 文字孔洞、转曲文字孔洞和描边线框镂空。
- 封面与体块顶面颜色恢复。
- 拉伸后顶面、底面与侧面朝向修复。
- 路径端点自动吸附。
- 自适应曲线细分、边界焊接和快速体块构建。
- `maskPaths`、`surfacePathId` 与 `uvCrop` 图片处理。
- 图片材质按文件路径与名称生成唯一缓存键，避免同名覆盖。
- 颜色格式标准化。
- SketchUp 原生目录选择器。
- Windows 与 macOS 路径兼容。
- 每次点击导入时删除历史日志与旧备份，只生成当前一次导入日志。

## 数据流

普通导入：

1. 点击导入时重置日志。
2. 读取并标准化 JSON。
3. 修复路径端点。
4. 按文字、复合路径、普通路径、组和图片构建几何。
5. 对齐总组左下角到原点。
6. 保留总组作为最终结果。

叠层导入：

1. 执行普通导入的解析和标准化步骤。
2. 将顶层路径和顶层组整理为图层单元。
3. 根据 `zIndex` 或数组顺序排序。
4. 每个图层单元在独立子组内调用当前稳定几何构建器。
5. 按层间距施加 Z 偏移。
6. 对齐并保留总组和图层子组。

## 错误处理

- 导入仍由一个 SketchUp operation 包裹，失败时 `abort_operation`。
- 层间距无效、非数字或小于等于零时回退到 10mm。
- 坐落操作忽略不支持的选择对象；没有可处理对象时静默结束。
- 坐落单个对象无命中时不移动，继续处理其他对象。
- 贴图对齐缺少参考对象时提示用户先选择组或组件。
- 图片选择取消不记错误、不弹窗。
- 图片创建失败或 API 异常时回滚并提示。

## 验证标准

### 自动化验证

- 图层排序：有效 `zIndex`、重复 `zIndex`、无 `zIndex`。
- 图层高度：第一个视觉顶层位于最高 Z，层间距准确。
- 参数兼容：未传新参数时行为与 v3.6.2 一致。
- 无效层间距回退为 10mm。
- 新操作模块和热重载文件列表完整。
- RBZ 顶层结构正确，包含加载器和模块目录。

### SketchUp 实际验证

- 普通封面：文字、转曲文字、描边框孔洞正确，颜色正确。
- 普通体块：孔洞、顶面颜色和侧面朝向正确。
- 叠层封面与体块：层序、间距、总组与子组结构正确。
- 选择框与实际几何一致。
- 落面：平面、不同高度、多对象、无命中。
- 贴图：尺寸、XY 对齐、Z 高度、取消选择。
- 热重载与重启均无 Ruby 加载错误。
- 面板显示 v3.6.3，原功能和布局保持可用。
