# 端点吸附与选区轮询优化设计

## 范围

本阶段只允许调整以下两项：

1. SketchUp 导入端的大量路径端点自动吸附性能与分组正确性。
2. Illustrator 面板的选区轮询与导出完成状态保持。

此前列出的 PNG 清理、临时文档恢复、JSON 写入、导入结果反馈、材质刷新、白色材质等事项不在本阶段范围内。

## SketchUp 端点吸附

`Importer#snap_path_endpoints!` 保持现有 0.05 mm 最终模型容差。它将端点按容差大小映射到二维网格，只比较本格和周围八格的端点；距离满足容差的端点通过连通分组合并为一个吸附簇。

每个簇使用所有成员的平均坐标更新端点。同一路径的首尾端点落在同一簇时，才标记该路径为闭合。每个端点只属于一个簇，避免旧两两扫描使重叠邻域重复吸附。实现不引入第三方依赖。

## Illustrator 面板选区轮询

面板将轮询定时器集中到一个控制点管理：

- 面板隐藏时停止定时器；重新显示时仅在未导出且未锁定结果时恢复。
- 开始 PNG 或 JSON 导出时停止定时器。
- 导出结束后锁定状态文字，后台不再查询或覆盖结果。
- 用户下一次操作面板时解除结果锁定并恢复选区查询。
- 面板卸载时清除定时器。

“下一次操作面板”包括导出、浏览目录、打开原生导出对话框和热重载。选择变化不会自行覆盖上一次导出结果。

## 验证

- Ruby 回归测试覆盖相邻网格、经中间端点传递连通的吸附簇，以及每个端点只参与一个结果簇。
- JavaScript 测试覆盖导出期间、隐藏期间、结果锁定期间不发起选区查询，以及下一次面板操作后恢复查询。
- 现有协议和快捷键移除测试继续通过。
