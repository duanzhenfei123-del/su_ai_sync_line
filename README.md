# SU+AI 导入

`SU+AI 导入` 是一个 SketchUp 插件，用于将 AI 侧导出的同步数据导入 SketchUp，支持路径、分组、图片以及文字轮廓等内容。

本仓库用于发布插件安装文件、源代码与使用说明，方便学习、交流、安装与二次改进。

## 仓库内容

- `su_ai_sync_v3.6.rbz`：SketchUp 插件安装包
- `SU_AI_PNG_Export_v3.6_Setup.exe`：配套安装程序
- `SU_AI同步插件_v3.6_使用说明书.pdf`：使用说明文档
- `source/`：从 `rbz` 包整理出的插件源码

## 主要功能

- 从指定目录读取 AI 导出的 `.json` 同步数据
- 导入路径、分组、图片与文字轮廓
- 支持快速导入与控制面板两种使用方式
- 支持导入比例调整
- 支持曲线细分精度设置
- 支持生成封面/面
- 支持按厚度拉伸成立体几何
- 支持自定义导入目录

## 安装方式

### 方式一：直接安装插件包

1. 打开 SketchUp。
2. 进入扩展管理器。
3. 选择安装扩展。
4. 选中 `su_ai_sync_v3.6.rbz` 完成安装。

### 方式二：查看或修改源码

如果你希望学习实现方式，或在非商业前提下进行自定义修改，可以直接查看 `source/` 目录中的 Ruby 源码。

## 使用说明

1. 在 AI 侧导出同步数据到指定文件夹。
2. 在 SketchUp 中打开 `SU+AI 同步` 插件。
3. 选择导入目录、比例、曲线精度等参数。
4. 点击“直接导入”或通过控制面板执行导入。

更详细的图文说明请查看：

- `SU_AI同步插件_v3.6_使用说明书.pdf`
