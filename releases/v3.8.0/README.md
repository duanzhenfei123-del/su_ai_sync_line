# SU+AI 同步 v3.8.0

发布日期为 2026-11-22。本次为功能更新，包含 SketchUp 端「DTT 同步导入」及 Illustrator 端「DTT 轮廓与图片导出」。

## 更新内容

- **同画板分批导入。** Illustrator 导出轮廓时，若导出内容完全位于同一画板内，会记录该画板的左下角。SketchUp 选择「自动定位」后，同一画板分批导入的图形会保留相对位置。旧同步数据或内容无法归入单个画板时，仍按对象左下角归零。
- **鼠标预览放置。** 选择「跟随鼠标」后，可以在模型视口预览导入轮廓并捕捉面、顶点和边中点。左键确认，Esc 取消。
- **面板调整。** SketchUp 面板按目录、放置、导入参数和导入状态排列。辅助工具集中在面板下方，维护操作放在右上角齿轮菜单。
- **DTT 署名与版本。** 两端面板显示插件名、段土土署名和实际运行版本，标题区的「打赏」按钮可打开随安装包提供的微信与支付宝收款码合图。
- **保留升级兼容性。** 两端沿用原安装路径、配置和 schema 2 数据协议。SketchUp 原「SU+AI 同步」工具栏继续使用原注册名，并通过宿主恢复布局。

## 安装与升级

1. SketchUp 用户在「扩展管理器 → 安装扩展」中选择 `SU_AI_Sync_Import_v3.8.0.rbz`，也可使用现有工具栏打开面板。当前会话热重载后可使用新版面板，下次启动后扩展菜单会显示「DTT 同步导入」。
2. Windows 用户运行 `SU_AI_PNG_Export_v3.8.0_Setup.exe` 更新 Illustrator CEP 扩展，然后从「窗口 → 扩展功能」打开「DTT 轮廓与图片导出」。部分宿主版本将该菜单显示为「扩展（旧版）」。
3. 两端均升级至 `v3.8.0` 后，可从 Illustrator 重新导出轮廓以使用画板定位。已有同步文件仍可导入。
4. `SHA256SUMS.txt` 提供两个安装成品的校验值。

## 已知限制

- 凹形或复合剪切蒙版超出图片边界、包含多个对象的复杂蒙版仍有导出限制。图片透明像素的边缘不会被自动描摹。
- 手机微信和支付宝实际扫码、其他宿主版本和平台、SketchUp 工具栏拖动与停靠及跨重启布局恢复、EXE 向导完整交互，以及完整的跨端人工联测尚未验证。
